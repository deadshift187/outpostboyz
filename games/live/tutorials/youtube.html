Connect your YouTube Live

Super Chats, Super Stickers and memberships change the game while you play. First time takes about 10 minutes (you make a free "key" once), then 1 minute.

What you need

  • The Google account you use for YouTube
  • A free YouTube API key. Part 1 below shows how to make one. It's free, and you won't be charged.
  • Your live stream set to Public. Super Chats don't work on unlisted, private or "made for kids" streams.
  • The game open in Chrome, Edge or Firefox on your computer
  • Your streaming app. See Put the game on your stream

Why a key? YouTube only shares live chat with apps that have a key. Using your own key means you get your own daily limit, and your key only works on outpostboyz.com.

Part 1: make your key (one time only)
  1. Go to console.cloud.google.com and sign in. If it asks, agree to the terms and create a project. Name it anything, for example outpost-live.
    SCREENSHOT: Google Cloud "New project" screen
  2. In the search bar at the top, type YouTube Data API v3, open it, and click Enable.
    SCREENSHOT: YouTube Data API v3 page with the Enable button
  3. Open the menu, go to APIs & Services, then Credentials. Click + Create credentials, then API key. A key that starts with AIza appears.
    SCREENSHOT: "API key created" box
  4. Lock the key so nobody else can use it. Click Edit API key (or the key's name).
    • Under Application restrictions, pick Websites. Add outpostboyz.com/* and also *.outpostboyz.com/*.
    • Under API restrictions, pick Restrict key and tick only YouTube Data API v3.
    • Click Save.

    The lock can take a few minutes to start working.

    SCREENSHOT: key restrictions filled in (Websites + YouTube Data API v3)
  5. Click Show key and copy it. Keep it somewhere safe, like a password manager.
Part 2: connect the game (every stream)
  1. Start your YouTube live stream (Public) and copy its link, for example youtube.com/live/abc123.... Your channel @handle also works once you're live.
  2. Open the game on outpostboyz.com, click LIVE MODE, open LIVE SETUP and tick YouTube.
    SCREENSHOT: game Live mode with YouTube fields (key + stream link)
  3. Paste your key and your stream link, then click Connect. You should see Found "your stream title", LIVE now.

    The game remembers your key in this browser only, so next time you just paste the new stream link.

  4. Click Test a Super Chat. Something should happen in the game.
  5. Close the settings panel and play. Super Chats, Super Stickers, new members and gifted memberships change the game. Chat messages give small boosts.

Troubleshooting

"API key not valid"

Copy the key again. It starts with AIza and has no spaces.

"This key is blocked for this website" (or "referrer blocked")

Check step 4. Both outpostboyz.com/* and *.outpostboyz.com/* must be there, spelled exactly. Wait 5 minutes, then try again.

"YouTube Data API has not been used" or "disabled"

Do step 2 again: search for YouTube Data API v3 and click Enable.

"Not live yet" or "stream ended"

Start the stream first. Paste the link of today's stream, not an old one.

Chat works but no Super Chats come in

Your stream must be Public and not marked "made for kids", and Super Chat must be turned on for your channel.

"Daily limit reached"

Your key's free daily allowance ran out. It resets the next day (Pacific time). Very long streams can hit it, so reconnect less often.

Is there a way without a key?

No. YouTube doesn't let websites read live chat without one.

House rules

Super Chats change the game only. Never run a "Super Chat to win" contest. YouTube contests must be free to enter.
