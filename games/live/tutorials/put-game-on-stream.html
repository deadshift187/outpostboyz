Put the game on your stream

Show the game you're playing to your viewers, in OBS, Streamlabs or TikTok LIVE Studio.

What you need

  • A Windows or Mac computer. For TikTok with TikFinity, it must be Windows.
  • The game open in Chrome or Edge (Firefox is fine too)
  • One streaming app: OBS Studio, Streamlabs Desktop or TikTok LIVE Studio
  • Best: two screens, with the game on one and your streaming app on the other

The one rule

DO: capture the browser window you are playing in (Window Capture).

DON'T: add the game as a Browser Source (OBS, Streamlabs) or a Link source (LIVE Studio).

Why: a Browser Source opens a second copy of the game inside your streaming app. Your viewers would watch copy #2 while you play copy #1, and gifts would go to both.

Step 1: pick your shape and pop the game out

  1. Open the game, click LIVE MODE, and connect your platform (Twitch, TikTok or YouTube).
  2. Pick your shape:
    • Tall (9:16) for TikTok, YouTube Shorts-style, and phones
    • Wide (16:9) for Twitch and regular YouTube
  3. Click Pop out stream window. The game opens in its own clean window (no tabs, no bookmarks) at the right shape. Play in this window.

    If nothing opens, allow pop-ups for outpostboyz.com (click the icon at the right end of the address bar).

Step 2: capture it in your app

OBS StudioStreamlabs DesktopTikTok LIVE Studio

OBS Studio

  1. Set your canvas. Go to Settings, then Video.
    • For TikTok, set Base and Output to 1080x1920.
    • For Twitch or YouTube, set both to 1920x1080.
    Set FPS to 30 or 60, then click OK.
    SCREENSHOT: OBS Settings, Video, with 1080x1920
  2. Under Sources, click +, then Window Capture, then OK.
  3. In Window, pick the game window. It looks like [chrome.exe]: CLIMB OR DIE. Set Capture Method to Windows 10 (1903 and up). If you see a Capture Audio box, tick it.
    SCREENSHOT: Window Capture properties with the right window and capture method
  4. Right-click the source, choose Transform, then Fit to screen. The game now fills your canvas.
  5. Add your camera and mic. Viewers like to see you react, and TikTok expects you to be there.

Want both shapes at once? OBS plugins such as Aitum Vertical add a second, tall canvas. That's optional.

Streamlabs Desktop

  1. For TikTok, go to Settings, then Video, and turn on Dual Output. That gives you a tall 1080x1920 canvas next to the wide one. Otherwise, keep the normal 1920x1080.
  2. Click + next to Sources, choose Window Capture, and select the game window.
    SCREENSHOT: Streamlabs Window Capture picker
  3. Resize the source to fill the canvas. With Dual Output on, make sure it's visible on the Vertical canvas.

TikTok LIVE Studio

  1. Keep LIVE Studio in portrait (tall) for a normal TikTok LIVE.
  2. In your scene, click Add source, then Window capture, and pick the game window.
    SCREENSHOT: LIVE Studio "Add source" menu with Window capture
  3. Drag the corners so the game fills the frame. Add your camera too.
  4. Don't use Link source for the game. It's a second copy, the same problem as a Browser Source.

Keep the game running smoothly

DoWhy
Keep the game window visible: on a second screen, or side by side with your appBrowsers pause games that are minimized or fully covered, and your stream would freeze
Play in the same window you captureAnything else is a different copy of the game
Close the Live mode settings before going liveSo your keys never show on stream
Click Test a gift before you go liveTo check the scene and the connection together

Troubleshooting

The capture is black

In the Window Capture settings, set Capture Method to Windows 10 (1903 and up). If it's still black, turn off hardware acceleration in the browser (Settings, System, "Use graphics acceleration") and restart the browser.

My game window isn't in the list

Make sure the pop-out window is open and not minimized, then close and reopen the source's properties.

The game freezes on stream when I click OBS

The game window is covered or minimized. Move it so you can see at least part of it, ideally all of it.

Black bars around the game

Your canvas and your game shape don't match. Pick Tall for a 1080x1920 canvas, or Wide for 1920x1080, then Fit to screen again.

Viewers' gifts don't show in the game on stream

You're capturing a Browser Source or Link source (a second copy). Delete it and use Window Capture of the window you play in.

No game sound on stream

Tick Capture Audio in the Window Capture settings if you have it. Otherwise, make sure Desktop Audio is on in your app's mixer.

Mac users

OBS on Mac uses macOS Screen Capture, set to "Window". Allow screen recording for OBS when macOS asks.
