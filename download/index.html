01 / iPhone + iPad

Add to Home Screen

Apple only allows installs from Safari — it takes about ten seconds.

  1. Open outpostboyz.com in Safari (not Chrome or an in-app browser like TikTok or Instagram).
  2. Tap the Share button — the square with the arrow pointing up.
  3. Scroll down and tap Add to Home Screen, then Add.
  4. Launch Outpost Arcade from your home screen once while you're online, and open each game you want. After that they play offline — full screen, no browser bars.

RUN THE BOARD's recorded host voice needs a connection; offline it switches to your phone's built-in voice.

02 / Android + PC / Mac

Install the app

Chrome and Edge can install the arcade as a real app with its own icon and window.

INSTALLED — CHECK YOUR HOME SCREEN / APPS

No install button? Your browser handles it from its menu — steps below.

  1. Android (Chrome): tap the ⋮ menu → Install app (or Add to Home screen) → Install.
  2. PC / Mac (Chrome): click the install icon at the right end of the address bar, or ⋮ → Cast, save and share → Install page as app.
  3. PC (Edge): … menu → Apps → Install this site as an app.
  4. Open the app once online and play each game once — then it runs offline.

Firefox and Safari on Mac can still play everything in the browser; they just don't install it as an app.

03 / Arcade cabinet · Raspberry Pi · Batocera

The arcade pack

Put the free games on a Batocera cabinet as their own Outpost Boyz system — they run fully offline in a fullscreen kiosk. Made for keyboard-encoder panels (like an Ultimarc I-PAC) with a trackball.

DOWNLOAD THE PACK (.ZIP)
  1. Unzip outpost-arcade-batocera.zip on your computer.
  2. Copy the outpostboyz folder to /userdata/roms/ on the cabinet (over the network share \\BATOCERA\share\roms, or a USB stick).
  3. Copy es_systems_outpostboyz.cfg to /userdata/system/configs/emulationstation/.
  4. Over SSH (user root), make the launchers runnable: chmod +x /userdata/roms/outpostboyz/*.sh /userdata/roms/outpostboyz/_kiosk/*.bash
  5. Restart EmulationStation (Main Menu → Quit → Restart EmulationStation). Outpost Boyz shows up as a new system.

Exit any game with Start + Coin (1+5 or 2+6) or F10 on a keyboard.
